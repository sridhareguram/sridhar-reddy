my side project

CricClash

A free cricket game that runs in the browser. I'm the sole developer: a React front end on Cloudflare Pages, a rules-based simulation engine written in vanilla JavaScript, and real-time Versus multiplayer over WebSockets on Cloudflare Workers and Durable Objects.

  • Modes include Solo, Versus, Expert vs AI, Elite Pitch, Auction Trilogy and an IPL (T20) mode.
  • Every rating traces back to a researched season stat, and server-only datasets stay off the client.
  • The Man of the Match algorithm replicates real-world panel bias and is calibrated on 120 matches.
  • I build it with AI: Claude researches, diagnoses and drafts prompts, Cursor implements, and I check the result. Tests passed on one AI-built change while a bowler could still bowl past the legal overs limit in T20. I only caught it by playing real scenarios.

React, JavaScript, Cloudflare Pages, Workers and Durable Objects, WebSockets

from a hackathon

AURA

AURA, the Autonomous Understanding and Reflective Agent, is an empathetic multi-agent AI companion inspired by the film Her. It was built for the Luddy Hackathon (Case 4), and it listens to how you feel, writes about it, finds things to lift your mood and answers like it cares.

  • Emotion Analyzer classifies mood with a fine-tuned RoBERTa model.
  • Memory Agent keeps mood history across sessions.
  • Journal Agent writes timestamped poetic entries.
  • Curator Agent finds media through YouTube, Spotify and Tavily.
  • Support Agent replies with metaphor-rich empathy.
  • Fallback Agent keeps things working when an API or model fails.
  • Base Agent handles shared OpenAI access and prompts.

The agents pass messages through a custom protocol that shares context and user history. A React dashboard shows what every agent is doing as it happens, and ElevenLabs adds voice in and out.

Python, FastAPI, React, LangChain, OpenAI API, Hugging Face Transformers, ElevenLabs
